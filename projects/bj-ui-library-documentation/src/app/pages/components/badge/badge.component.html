A badge is a small label that shows a status or a category.

 New
  1. Container: the background and the corner radius.
  2. Icon (optional): the badgeIcon slot, on the left or on the right.
  3. Text: the projected content.

Usage

  • To show the status of an item, such as active or pending.
  • To tag an item with a category.
  • To highlight something new.
  • For actions: a badge is not interactive, use a button.
  • For long messages: use a paragraph or an alert.
  • For a counter on a button: use the badge input of bj-button.
  • Use one or two words.
  • Use the same word for the same status across the product.
  • Give each color one meaning, and keep it.
  • The text is read as plain content, so write it to make sense on its own.
  • Never rely on color alone: the text must carry the meaning too.
  • bj-icon is hidden from assistive technology, so the icon adds nothing for screen readers.
  • Check the contrast when you choose a custom background.

Implementation scenarios

Any bj-bg utility works. Status colors suit status badges.
