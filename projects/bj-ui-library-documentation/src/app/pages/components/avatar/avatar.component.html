An avatar represents a person with the initial characters of their name.
  1. Container: a circle or a square with a colored background.
  2. Initials: the first two characters of userName, in uppercase.

Usage

  • To identify the author of a comment or a change.
  • To show the signed-in person in a header.
  • To make a list of people easier to scan.
  • As the only way to identify a person: show the name too.
  • To represent products or companies.
  • Pass the name the person uses in the product.
  • Remember that the avatar shows the first two characters of the name, not the initials of name and surname.
  • Use one size and one shape for the same kind of list.
  • Two letters do not identify a person for a screen reader: show the full name next to the avatar.
  • When the name is visible, add aria-hidden="true" to the avatar so it is not read twice.
  • Check the contrast when you change the colors with the custom properties.

Implementation scenarios

Four sizes, from 32 to 80 pixels.

Use the square shape when the interface has only straight corners.

Override --bj-avatar-background and --bj-avatar-color to change the colors.

The recommended pattern: the name is visible and read once.
