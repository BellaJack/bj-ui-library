An accordion shows and hides a section of content, so a long page stays easy to scan.

Orders ship within two working days.
  1. Button: toggles the content. The accordionButton slot replaces its default icon and label.
  2. Content region: the panel with an animated height.
  3. Content: what you project in the accordionContent slot.

Usage

  • To group secondary information, such as frequently asked questions.
  • To shorten a page with many independent sections.
  • To offer optional details inside a form or a filter panel.
  • For content that everyone needs to read: leave it visible.
  • For content that people compare side by side.
  • For a single short sentence, which does not need hiding.
  • Write labels that tell what is inside before opening it.
  • Keep labels short and parallel when accordions are stacked.
  • Keep the content short: a very long section deserves its own page.
  • The button is a native button, so it works with Enter and Space.
  • aria-expanded announces the state and aria-controls links the button to the content.
  • The content is a region named by its button.
  • A closed accordion is inert: its links cannot be reached with Tab.
  • Give every accordion a unique id, or the links between button and content break.

Implementation scenarios

Use the accordionButton slot and buttonClasses to style the button, for example as a bj-btn.
