Buttons let people trigger an action. Use <bj-button> for actions and <a bjButton> for navigation.

 Save
  1. Container: the native button or a element.
  2. Text: the projected content, visually hidden in icon-only buttons.
  3. Icon (optional): on the left or on the right of the text.
  4. Badge (optional): on the left or on the right, on the corner of icon-only buttons.

Usage

  • To submit a form or confirm a choice.
  • To start an action on the current page.
  • With <a bjButton>, for a navigation that needs the weight of a button.
  • For links inside a sentence: use a plain link.
  • For more than one primary action in the same area.
  • For danger actions that can be undone without consequences.
  • Start with a verb and name the result: "Save changes", not "OK".
  • Keep the text short, ideally one or two words.
  • Pick icons that reinforce the text, and keep the same icon for the same action.
  • Always project a text, or set ariaLabel: it is the only name an icon-only button has.
  • Use ariaLabel when the visible text needs more context. Keep the visible words in it, so voice control still works.
  • Icons are hidden from assistive technology, while the badge value is read after the text.
  • Native buttons work with Enter and Space, links with Enter.
  • A disabled button or link cannot be reached with the keyboard.
