A round icon places an icon inside a colored circle, to give it more visual weight.
  1. Circle: the colored background, sized by size.
  2. Icon: a bj-icon centered in the circle.

Usage

  • To mark a status next to a message.
  • To introduce the items of a feature list.
  • To give an empty state a focal point.
  • As a button: it is not interactive, use an icon-only bj-button.
  • To represent a person: use bj-avatar.
  • Inside a line of text: use bj-icon.
  • Use the status colors only for real statuses.
  • Choose simple, recognizable icons: small sizes lose detail.
  • Keep one size for the same kind of content.
  • The component is decorative: it always has aria-hidden="true".
  • The text next to it must carry the whole message, status included.
  • Never rely on the color alone to tell statuses apart.

Implementation scenarios

Five sizes, from 24 to 80 pixels.

The background follows the meaning of the content.

The bj-round-icon-text class aligns the circle with its message.
