An icon reinforces a message with a simple symbol, using the Font Awesome classes.
  1. Symbol: the glyph chosen with icon. It takes the color of the surrounding text.

Usage

  • Next to a text, to make it faster to recognize.
  • In a button, to reinforce the action.
  • In lists and menus, to tell the items apart.
  • As a clickable element on its own: use an icon-only bj-button.
  • As decoration that adds noise without adding meaning.
  • In place of a text when the symbol is not universally known.
  • Use the same icon for the same concept across the product.
  • Prefer the fas style, and avoid mixing styles in one view.
  • Match the icon size to the text next to it.
  • The icon always has aria-hidden="true": screen readers ignore it.
  • When the icon carries meaning, add the same information as text, even hidden with u-v-hidden.
  • Non-text content needs a contrast of at least 3:1 against its background.

Implementation scenarios

Six sizes, from 12 to 32 pixels.

Use classes with a bj-color utility to change the color.

When there is no visible text, add one for assistive technology.
